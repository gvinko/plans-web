Accurate house model workflow

  1. Return to the calibrated plans workspace.
  2. Import the PDF, PNG or JPG plan and set scale from a known dimension.
  3. Manually trace the walls; treat automatic detection only as a guide.
  4. Verify a known 3150 mm wall equals 31.50 mm at 1:100 before printing.
A calibrated, manual trace is the source of truth. Once a trace is calibrated, selection drops off so you can continue drawing cleanly.
